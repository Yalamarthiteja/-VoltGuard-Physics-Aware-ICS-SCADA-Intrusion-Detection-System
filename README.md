# VoltGuard
## Physics-Aware ICS/SCADA Intrusion Detection System

### Project Overview
VoltGuard is a physics-aware industrial cybersecurity system designed to identify potentially unsafe industrial control commands by evaluating their impact on simulated physical processes.

### Objectives
- Simulate industrial control commands.
- Predict physical process pressure.
- Identify unsafe operating conditions.
- Classify commands as ALLOW, BLOCK, or INVALID.
- Maintain security event logs.
- Provide a monitoring dashboard.

### Technology Stack
- Python
- NumPy
- Flask
- Matplotlib
- Pytest
